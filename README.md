# Schwurbleritis

Das interaktive Periodensystem des Schwurbliums.

Enthält unter anderem:

- Äther
- Wassergedächtnis
- Quantenheilung
- Bachblüten
- Klangschalen
- Körbler-Symbole
- Meridianpunkte
- Schüßlersalze

⚠️ Hinweis: Dieses Projekt ist Satire und dient ausschließlich der Unterhaltung.

Jegliche Ähnlichkeit mit real existierenden Seminaren zu energetischen Ausgleichszahlungen ist rein zufällig.
